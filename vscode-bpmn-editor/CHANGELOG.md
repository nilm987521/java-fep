# Change Log

All notable changes to the "FEP BPMN Editor" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.0.0] - 2024-01-19

### Added
- Visual BPMN editor with drag-and-drop support
- Java Delegate scanner for automatic discovery of Camunda delegates
- Delegate tree view in Activity Bar
- Support for Camunda BPMN extensions
- Properties panel for editing element attributes
- Export to SVG/PNG functionality
- Syntax highlighting for BPMN files
- Auto-scan delegates on workspace open

### Features
- **BPMN Editor**: Full-featured BPMN 2.0 modeler based on bpmn-js
- **Java Delegate Integration**: Scan and display Java delegates from your project
- **Camunda Support**: Native support for Camunda-specific BPMN extensions
- **Category Organization**: Delegates organized by categories (驗證類、帳務類、電文類、通訊類)
- **Drag & Drop**: Drag delegates directly onto the BPMN canvas
